# Menu illustration

`menu-forge-v2.webp` is a reference-derived generated illustration commissioned for the VOIDFORGE main menu in this task. It follows the user's supplied scene, character, lighting and composition. It contains no baked menu text or buttons. The runtime needs no image-generation service.

- Size: 1672 × 941; optimized WebP, approximately 497 KiB.
- UI remains real HTML; animated traffic, drifting rocks, stars and the rotating/pulsing Forge aperture are independent Canvas layers in menuBackdrop.ts.
- Scope: menu only. Gameplay sprites, mining geometry and ship construction artwork are unchanged.
